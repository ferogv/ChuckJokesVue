# ChuckJokesVue

Minimal Vue 3 + Vite app for Activity 12: display a list of Chuck Norris jokes using components and v-for.

## What it does
- Returns the supplied `chuck` array from App.vue
- Renders the list with `v-for` using a child component (`ChuckItem.vue`)
- Provides a simple, aesthetic stylesheet

## Run locally (development)
Prereqs: Node 20.x or 22.x, npm.

1. Install
   npm install

2. Start dev server
   # from project root
   .\node_modules\.bin\vite.cmd
   # or
   npm run dev

3. Open the Local URL printed by Vite (typically http://localhost:5173/)

## Build / Preview
npm run build
npm run preview
